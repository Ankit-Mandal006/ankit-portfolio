# Gift Catchers

> *Catch the gifts. Dodge the bombs. Win the holidays.*

## Overview

A festive, low-poly arcade game where players race to collect falling presents dropped directly from Santa’s flying sleigh. Navigate across a snowy mountain homestead, catch green-glowing gifts in your container, and dodge dangerous explosive bombs to claim victory over your competitor or beat your own high score in single-player mode.

---

## Key Features

* **Competitive & Single-Player Gameplay:** Race against a second player locally or tackle the gift-collecting challenge solo.
* **Dynamic Dropped Hazards:** Collect high-value green-glowing presents while dodging incoming explosives dropping from above.
* **Low-Poly Winter Aesthetic:** Styled with 3D low-poly art featuring a starry night sky, mountain chalets, snowmen, and Santa’s reindeer sleigh pathing overhead.
* **Cross-Platform Precision:** Tailored control schemes built for both PC keyboard navigation and mobile multi-touch support.

---

## Gameplay & Image Breakdown

* **Active Play Field:** Features two low-poly avatars (Blue and Red) moving across a snowy mountain yard. Santa's sleigh flies above, dropping green-glowing gifts to collect and red explosive bombs to avoid. Dedicated UI badges at the top-left and top-right track each player's real-time score.
* **Victory Screen:** A stylized post-game summary board framed in Christmas string lights. It compares total gifts collected by each player (e.g., Blue x17 vs. Red 4x), announces the winner, and provides a quick button to return to the main menu.

### PC Controls

| Action | Input | Behavior |
| :--- | :--- | :--- |
| **Move Left** | `A` | Move character left |
| **Move Right** | `D` | Move character right |
| **Jump** | `Space` | Vertical jump |

### Android Touch Controls

| Action | Touch Gesture | Behavior |
| :--- | :--- | :--- |
| **Move Left** | `Touch Left Side` | Move character left |
| **Move Right** | `Touch Right Side` | Move character right |
| **Jump** | `Touch Both Sides` | Vertical jump |
