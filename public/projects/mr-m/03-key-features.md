# Key Features

## Key Features

* **Dynamic Badge Scaling:** Collecting badges continuously increases game difficulty, introducing harsher obstacles and faster hazards.
* **Multi-Genre Environments:** Experience diverse gameplay perspectives and levels, including top-down arena survival and classic 2D side-scrolling platforming.
* **High-Mobility Controls:** Master precise jumping and quick directional dashes to maneuver past crushing hammers, rolling boulders, and ambient hazards.
